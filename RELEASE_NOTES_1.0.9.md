# LOCAL 1.0.9

- Replaces the generic PDF import warning with a clearer confirmation showing the document name, page count and on-device processing behavior.
- Removes the outdated native PDF loading dialog so import feedback remains within LOCAL's interface.
- Protects captured pages from accidental loss when leaving a scan or pressing Android Back.
- Lets users save the scan, keep editing or explicitly discard it before leaving.
- Keeps the Android clock, status icons and navigation controls readable when the device uses dark mode.

LOCAL continues to process documents on the device. The original PDF remains unchanged when imported.
