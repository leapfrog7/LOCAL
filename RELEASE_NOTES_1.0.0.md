# LOCAL 1.0.0

LOCAL is a private, local-first Android document scanner and searchable archive.

- Scan or import multi-page documents with local OCR and barcode recognition.
- Search recognised text, folders, tags and smart document metadata.
- Organise PDFs with combine, extract, reorder, compress, page insertion and cleanup tools.
- Protect the app with device authentication and encrypt selected private documents.
- Export searchable PDFs or OCR text and create encrypted portable backups.
- No account, analytics, advertising, cloud document storage or remote OCR.
