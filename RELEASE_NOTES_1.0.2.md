# LOCAL 1.0.2

This release makes everyday document handling safer, faster, and less cluttered while keeping OCR and document processing on the device.

## Highlights

- Adds recoverable deletion with Recently Deleted, restore controls, and automatic 30-day cleanup.
- Adds guided encrypted backup and restore with conflict handling and clearer recovery guidance.
- Improves Library browsing with reliable date filters, folders, tags, sorting, list/grid views, recent searches, and bulk organisation.
- Adds a dedicated Actions area for combine, split, reorder, insert, compress, cleanup, and text export workflows.
- Improves Insert Pages with visual source-page selection, destination placement previews, and copy-or-replace choices.
- Adds page and continuous PDF viewing modes, fit controls, 25%–400% zoom, horizontal page swiping, and auto-hiding thumbnails.
- Redesigns the PDF viewer so Save copy, Share, and Open with live under Document options instead of obstructing the page.
- Adds page-level OCR extraction with selectable passages, **Copy selection**, and **Copy all**.
- Fixes continuous mode unexpectedly returning to single-page mode when a page is tapped.
- Improves Android Back behavior: one press returns to the Library and a quick second press minimizes LOCAL.
- Improves PDF import compatibility, background processing feedback, folder refresh, and month filtering.

LOCAL remains offline-first. Scans, imported documents, OCR text, search indexes, folders, and tags stay in private app storage unless you explicitly export, share, or create an encrypted backup.
