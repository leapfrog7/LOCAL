# LOCAL 1.0.3

This release makes reading, navigating and marking documents feel more natural while keeping every operation offline.

## Viewer and reading improvements

- Continuous pinch zoom and one-finger scrolling in portrait and landscape
- Virtualized page rendering for smoother large-document reading
- Per-document restoration of page, mode, zoom and scroll position
- Smart focal double-tap zoom and auto-hiding controls
- Compact page navigation with on-demand thumbnails
- Local bookmarks, original/sepia/night themes and keep-screen-awake preference
- Two-page spread and selectable offline Text view
- Offline system read-aloud

## Durable annotations

- Pen and highlighter tools with adjustable colour and width
- Whole-stroke eraser plus undo and redo
- Clear Pan and Drawing modes with show/hide control
- Automatic draft persistence and a simple Done action
- Optional annotated copy while preserving the original
- Rotation-safe normalized coordinates
- Annotated thumbnails, encrypted backups and searchable exported/shared PDFs
- Existing recognised text is preserved without unnecessary recognition reruns

## Privacy

LOCAL remains fully local-first: no accounts, analytics, cloud document storage or remote text-recognition service.
