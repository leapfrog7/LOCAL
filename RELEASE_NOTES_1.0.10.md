# LOCAL 1.0.10

This release turns annotation into a safer, more complete document-review workflow.

- Adds automatic recovery for unfinished annotation drafts. Android stores drafts in LOCAL's encrypted database.
- Simplifies the annotation toolbar and keeps less-used controls behind an expandable options panel.
- Adds selection, movement, recoloring, stroke presets, and deletion for individual annotations.
- Replaces whole-stroke erasing with a precise partial eraser for freehand marks.
- Adds OCR-aware highlighting that snaps rough gestures to recognised words.
- Adds lines, arrows, rectangles, ellipses, and editable positioned text notes.
- Improves phone and landscape layouts, touch targets, save feedback, and annotation accessibility labels.

Annotations are flattened into LOCAL's generated PDF when saved. Save a copy when the original document must remain unchanged.
